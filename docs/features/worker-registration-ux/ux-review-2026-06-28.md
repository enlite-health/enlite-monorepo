## 🎯 Problema central (prioridade máxima)

**Salvar não conduz: após `Guardar` o app não avança de etapa e não há botão visível de "continuar".**

- É a crítica mais repetida e enfatizada na narração (transcript:21-22, 26, 35, 57-59).
- Citação: *"el prestador no puede olhar ese botoncito aquí para continuar el fluxo… yo presiono guardar y directamente pasar para la próxima tela"* (transcript:21-22).
- Confirmação nos frames: navegação entre etapas só pelas setas `<` / `>` no topo (f_364, f_454–456); rodapé só tem `Guardar` (f_205, f_239, f_251); ao salvar, a tela **reflui ao topo** em vez de avançar (f_257–259, f_321–324).
- **Pedido do autor**: substituir o `Guardar` isolado por **`Atrás` / `Siguiente`** que salvam ao avançar e levam à próxima etapa automaticamente, terminando numa tela que mostre o que ainda falta (transcript:27-28, 50-56).

## Backlog priorizado

Legenda: **[BUG]** defeito · **[MELHORIA]** ajuste de UX. P0 = bloqueia o fluxo; P1 = alto impacto; P2 = polimento.

### P0 — fluxo
- [ ] **[BUG]** Salvar não avança e volta ao topo. Implementar navegação `Atrás/Siguiente` (salva no `Siguiente`) ou auto-avanço pós-save. _Ev: transcript:21-28,57-59; f_257–259, f_321–324._
- [ ] **[BUG]** Sem feedback de sucesso ao salvar → usuário reclica `Guardar` (risco de submit duplo). Add toast/estado "guardado". _Ev: f_257–259, f_321, f_353, f_360._
- [ ] **[MELHORIA]** Sem tela/mensagem de finalização — o ciclo não fecha. Tela final com documentos faltantes + CTA. _Ev: transcript:50-56; f_709–726._

### P1 — entrada de dados
- [ ] **[MELHORIA]** Documentos obrigatórios sem sinalização por item — add legenda "(obligatorio)" sob cada card, **sem bloquear** upload (só o Seguro é opcional). _Ev: transcript:37-49; f_459–460._
- [ ] **[MELHORIA]** Defaults pré-selecionados induzem erro: `Profesión`, `Nivel de Estudios` (=Secundario), `Sexo/Género` (=Masculino) — começar sem seleção. _Ev: transcript:13-16; f_126, f_128, f_167–170, f_204._
- [ ] **[MELHORIA]** Seletor de horário em incrementos de 5 min força scroll longo — usar **30 min**. _Ev: transcript:30-33; f_368–369, f_410–433._
- [ ] **[BUG]** Mapa diverge do endereço digitado (POIs de outra região com `Dirección = Resistencia`). _Ev: f_338._
- [ ] **[BUG]** Validação on-keystroke agressiva: erro no 1º caractere de `Nombre` (f_153); "Documento inválido" durante CUIL parcial (f_171–174); mensagem fala "nivel de conocimiento" mas label é "Nivel de Estudios" (f_213–214). Validar on-blur / mensagens coerentes. _Ev: f_153, f_171–174, f_213–214._

### P2 — consistência / polimento
- [ ] **[BUG]** Layout quebra ao adicionar documento extra ("se acomodó el botón +"). _Ev: transcript:42-43; f_535–563._
- [ ] **[BUG]** Idioma misto / nome genérico: "Hola, **Usuário**, esta es su página principal" (PT em UI ES); `<html lang="en">`. _Ev: f_109, f_48._
- [ ] **[BUG]** Ortografia em labels: "¿Con **que**… te **gustaria** acompañar?" (vs gêmeo correto "¿Con qué…"); "Otra **Documentacion**". _Ev: f_205, f_239, f_563._
- [ ] **[MELHORIA]** `Sexo` e `Género` são dois selects idênticos lado a lado (parecem duplicados) — diferenciar ou unificar. _Ev: f_162–170._
- [ ] **[MELHORIA]** Discrepância de contagem: Home mostra "Documentos (1/4)" vs ~9 tipos na tela de Documentos — alinhar a métrica. _Ev: f_635 vs f_601–632._
- [ ] **[MELHORIA]** Gate de postulação revelado tarde (modal "Complete su registro" só ao clicar "Ver Detalles" após navegar 335 vagas) — antecipar o aviso. _Ev: f_118–123, f_656. (comportamento de gate conhecido do produto)._
- [ ] **[BUG]** Erros de console em `/worker/profile` (1 erro + 2 warnings; contador sobe ao salvar). Investigar causa. _Ev: f_126, f_321._
